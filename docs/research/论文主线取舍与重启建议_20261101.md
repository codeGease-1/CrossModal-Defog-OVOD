# 论文主线取舍与重启建议

日期：2026-11-01。用户目标：形成有明确创新点的论文。本轮仅调研与审定研究设计，不增加模型分支、不训练、不改动历史实验。以下区分已核对的文献事实、项目证据和研究建议。

## 判断

**建议重启论文问题与数据设计，保留现有工程基础。停止把“三先验动态融合”或“加语义校正”预设为论文主贡献。**

现有代码能继续用于数据读取、受控生成、固定标定、直接回归、原景分组、评价、恢复与复现。已有实验也有价值：逐图拉伸损失强度信息、动态融合在受控协议中优于固定融合、同骨干 RGB 回归更强，以及候选包络限制。这些是可以复用的研究事实。

代码重写不会消除当前最主要的限制：任务目标多次变化，监督和真实评价没有闭合，数据内容不足以验证语义假设，架构设计先于问题证据。这是本次建议调整研究设计的原因。

## 对前一阶段执行的修正

前一阶段用了通用 ADE20K 语义模型，在程序化纹理上拟合类别校正。这能排查特定实现和特定语义来源，却不足以检验遥感地物语义的普遍价值。应当先完成领域与数据适配调研，再决定这个探针是否值得做。这个顺序问题应当由执行者承担，不能通过提出更多分支转给用户。

49.5% 是相对于清晰输入预测的**类别保持率**，不是语义准确率；70% 是探针中人为预设的筛查门槛，不是文献公认的遥感有效性标准。条件映射全部回退总体，意味着本次最终 C 没有实际利用地物条件，不能以其结果证明“语义方法没有用”。

同样，RGB 在程序化条件下胜出，只能说明现有凸融合约束没有体现相对优势，不能直接指定它为真实遥感的最终方案。本次保留全部原始证据，收窄解释，不改写旧结果。

## 根本问题：到底在估计什么

现有项目曾依次使用先验伪标签分数、合成 H=1−t、原始彩色透射率的 H_eff、真实遥感雾感等对象。它们不能共享一个未限定的“雾浓度准确”结论。

在简化散射模型 I=tJ+(1−t)A 下，若某区域 J=A，则 I=A，与 t 无关；同一个 RGB 可以对应不同透射率。J 接近 A 时，输入对 t 的变化也较不敏感。这是由模型直接得到的可辨识性分析，不是新实验结果。自然遥感还包含成像、光谱与处理流程差异。

因此，单 RGB 或从该 RGB 派生的语义能够利用统计先验，但不能保证从所有地物上唯一恢复物理透射率。更高分并不总是更浓雾，较高模型置信也不等于可靠物理测量。若论文目标是实测气溶胶或消光，需要额外观测、配准和独立校验，现有数据与预算没有支持这一承诺。

## 建议保留的一条论文问题

**研究问题：遥感图像的雾强度估计，在多大程度上测量了地物内容；怎样验证其跨地物与跨成像条件的数值可比性？**

建议先将论文组织为“机制分析 + 地物受控评价基准 + 可复现简单基线”。明确创新候选是一个尚需审定的**评价问题与证据体系**，不预先承诺某个新网络。若目标投稿必须有显著方法创新，这份基准只能作为选题基础，不能直接许诺满足要求。

它必须比已有“已知雾级序列上的排序/比例评价”多回答三个具体问题：

1. 固定雾目标，改变地物内容时，预测产生多少系统偏差？建筑、水体、植被分组由独立地物标注确定，不由估计器自己生成。
2. 在原景/时空域隔离、亮度与大气光变化、合成协议变化下，绝对数值是否仍可比？不只报告同景排序。
3. 哪些区域对 t 缺少观测信息、哪些失败由模型引入？在受控真值和独立真实评价之间，哪些结论能够迁移，哪些只能限定在合成环境？

以上是基于本项目证据与本次文献核对提出的研究建议，**没有证据证明这一完整交集尚无人研究**。投稿前仍须对最接近的工作作逐项差异表；检索不到同名论文不能作为创新证明。

## 有边界的推进方式

后续按三个固定交付推进，避免把每个失败转成一个新模型分支：

| 交付 | 内容与约束 | 不满足时的决定 |
|---|---|---|
| 论文资格审定 | 固定一个目标期刊/会议范围；列最近邻工作的目标、数据、标签、输入、协议；写出能被审稿人检验的区别 | 暂停该选题；不靠更换网络名称继续 |
| 数据资格审定 | 优先检查 FLAIR 的小包、元数据和 RGB 通道；验证原景/area/时空域隔离、地物覆盖、基准合成与独立真实评价的可实施性；此时不训练 | 先解决评价资料，或结束这条选题；不再用程序化纹理替代遥感证据 |
| 一次固定基线研究 | DCP、FADE、现有三先验作为基线；只新增一个 RGB 学习基线，在新协议上重训；固定划分、指标、预算与未见测试，检查预先提出的地物混淆命题 | 若研究命题不成立或不区别于既有工作，保留证据并结束命题；不自动增加语义、门控、残差分支 |

新数据协议下旧模型分数不可充当同等训练条件的结果。FLAIR 本身提供 RGB/NIR/高程等数据；若限定 RGB 任务，只能使用相应通道，不能悄悄把额外观测给某一模型。地物真值首先服务独立评价，不作为部署输入。已处理的航空影像也不是原始辐亮度；在其上增加已知 t 的结果仍叫受控附加退化，不叫实测自然雾真值。

若没有可获得的独立真实评价，应在投入大规模训练前决定是否接受受控基准论文的定位，不能事后把合成结果扩大为真实结论。新增数据审核和人工评价需要时间；此前约 54 分钟 GPU 的试验消耗既不要求丢弃已有成果，也不能变成继续投入旧架构的理由。本轮没有核算出新协议的可信 GPU 报价，不能沿用旧协议的时长作保证。

## 如何理解“从头开始”

| 对象 | 建议 |
|---|---|
| 仓库、基础模块、恢复和评价工具 | 保留，减少重复工程 |
| 旧权重、失败图与历史结论 | 保留，作为基线与研究过程证据 |
| 程序化合成 | 保留为实现检查和机制诊断；不继续充当真实遥感语义有效性的主要证据 |
| 三先验、动态融合、语义校正必须成为创新点的预设 | 停止 |
| 论文目标、数据资格和最终评价设计 | 重新审定 |
| 立刻换一个更大网络或冻结大模型再试 | 暂不开展 |

研究问题审定通过后再选择方法，才能让每次实验回答一个固定问题，而不需要不断修补预定架构。当前能够确定的取舍是：结束围绕既定融合架构追加模块的推进方式，复用工程资产，重新建立论文成立所需的证据。
