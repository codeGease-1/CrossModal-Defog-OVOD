# 三先验与物理先验：代表性近期论文及项目定位

调研日期：2026-11-01。目的：判断三先验是否仍有论文空间，分析已有机制及与当前雾强度估计的区别。本次没有启动训练、改动模型、提交或推送。

## 结论先行

三先验值得继续研究。此前从“现有凸融合不占优”推到“暂停三先验主线”，判断过早。近期论文仍使用多先验、先验校正及先验引导融合。但“使用三种先验”“加动态权重”“增加校正分支”已经不足以单独构成明确创新。

当前更值得收敛的问题是：**三先验的内容相关偏差及共同失效能否被可验证地校正，且这种校正是否改善绝对雾强度估计，而非仅改善去雾观感？** 这是候选研究问题，不是已经证实的创新或有效方法。

## 调研范围与证据等级

阅读了下列论文的方法及实验正文，而非仅依据题目或综述：PGH²Net、DGFDNet、DPSF-Net、UR2P-Dehaze、Deep Variational Bayesian Modeling、Image based fog density estimation。另参考 PhDnet 作者仓库摘要。检索覆盖近期物理先验、多先验、遥感去雾与雾密度估计；这是一组有针对性的代表性工作，不能据此宣称穷尽所有最新论文。

PGH²Net、DGFDNet、DPSF-Net、UR2P-Dehaze 在本文按所读 arXiv 版本讨论，未核实正式发表状态，不称为已发表顶会成果。作者报告的最好结果不等于独立复现结论。各文的数据与任务不同，不跨表比较 PSNR 或推断本项目收益。

## 1. PGH²Net：直接相关的“三先验”方法

- 文献：Prior-guided Hierarchical Harmonization Network for Efficient Image Dehazing；所读版本 2025-03-03 v1。
- 原文：[arXiv 正文](https://arxiv.org/html/2503.01136v1)。
- 三种先验是暗通道、亮通道、直方图均衡化，**不是本项目的暗通道、局部对比度、颜色差异**。
- 机制：在特征域计算局部最小/最大响应，与原特征拼接后门控聚合；另通过直方图分布引导通道响应，并配合空间、通道处理。
- 监督与证据：以清晰图像重建为目标，多尺度空间、频域和结构损失；测试包含合成及真实成对去雾数据，没有独立验证其内部响应等于透射率或雾强度。
- 对项目的启发：先验可以作为特征归纳偏置，而不必先变成三张最终强度图再凸融合。但特征融合的表达力和难以解释程度都更高，不能将内部门控直接解释成物理可信度。
- 创新重叠风险：简单地把三先验输入轻量网络，再做注意力或门控，已有很近的机制先例。

## 2. DGFDNet：最需要正面对比的“先验校正”工作

- 文献：Efficient Dual-domain Image Dehazing with Haze Prior Perception；2025-07 首版，所读 v3 修订于 2026-02-14。
- 原文：[arXiv 正文](https://arxiv.org/html/2507.11035v3)。
- 机制：暗通道引导频率调制，多层门控聚合；PCGB 接收去雾分支反馈，逐层修正暗通道引导特征，并反复与初始暗通道特征融合，减少漂移。
- 关键区别：校正对象是暗通道的隐特征，不是三张具有共同 H=1-t 单位的候选估计。其最终损失约束重建图像的空间与频域误差，未设置独立 H 真值对先验校正的直接监督。
- 对项目的启发：固定先验会出错，学习过程应能修正错误；这个方向有文献支持。但“可学习先验校正”本身已非空白。
- 可以进一步追问：校正后是先验的物理估计更准，还是网络学会了绕过先验？当前项目若能用候选误差、共同偏差、可达范围及融合下界回答这一点，研究目标会比泛称校正模块更明确。

## 3. DPSF-Net：直接面向真实遥感的近期参照

- 文献：A Dual-Prior Spatial-Frequency Network for Real-World Remote Sensing Image Dehazing；2026-09-07 v1。
- 原文：[arXiv 正文](https://arxiv.org/html/2609.06962v1)。
- 机制：RGB 与暗通道分别嵌入后融合；空间—频率交互；先验引导注意力与可选择卷积核互补融合。所谓 dual-prior 输入是 RGB 和由 RGB 计算的 DCP，不是两个独立传感器。
- PGFAM 将注意力特征与先验增强特征用位置、通道相关权重融合。后者来自已经嵌入的 RGB-DCP 特征，不是重新得到一张可解释的透射率图。
- 监督与证据：重建、结构/小波相关及对比损失服务于去雾输出；真实遥感实验增加了领域相关性，但没有证明内部先验响应是准确的绝对雾强度。
- 对项目的启发：遥感场景下保留外观分支、允许削弱错误先验是合理设计。但亮地物上的权重变化不等于先验偏差已经校正。若我们也只做“遥感 + 先验 + 动态融合”，差异会很弱。

## 4. UR2P-Dehaze：把不同物理因素拆开处理

- 文献：Learning a Simple Image Dehaze Enhancer via Unpaired Rich Physical Prior；2025-01-12 v1。
- 原文：[arXiv 正文](https://arxiv.org/html/2501.06818v1)。
- 机制：共享先验估计器结合 Retinex 分解与迭代恢复过程，配合动态小波可分离卷积、自适应颜色校正及一致性约束。
- 对项目的启发：观测亮度、反射、照明、颜色与雾不能直接混为一谈。三张原始线索未必天然就是同一 H 的带噪观测，必须检验它们各自对场景内容的依赖。
- 局限：无配对恢复损失、Retinex 分解和增强效果，不能单独保证透射率可辨识。本文不据此建议增设一套复杂分解网络。

## 5. Image based fog density estimation：更接近本任务的三特征融合

- 文献：PLOS ONE，2025-06-02。
- 原文：[期刊正文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0323536)。
- 机制：JSFD 融合暗通道、调整后的饱和度和灰度点扩散相关统计量，采用加权线性组合；对天空、灰白物体等暗通道不适用场景讨论降低其权重。
- 评价：设计顺序误差与比例误差，利用已知密度的序列评估；任务比单纯去雾 PSNR 更接近本项目。
- 对项目的意义：多特征组合、按内容处理先验失效并非新问题。值得吸收跨图数值关系的评价，但其统计密度指标不能直接当成逐像素 H=1-t 真值。
- 需要区别：顺序或比例更好不代表绝对标定更准，也不代表已解决遥感困难地物。

## 6. Bayesian 物理建模：概念参照，不冒充最新论文

- 文献：Deep Variational Bayesian Modeling of Haze Degradation Process。arXiv 上传于 2024 年，但页面明确标注已发表于 **CIKM 2023**。
- 原文：[论文正文](https://arxiv.org/html/2412.03745v1)，[发表信息](https://arxiv.org/abs/2412.03745)。
- 机制：以清晰图像和透射率为潜变量，结合散射成像似然及先验，通过变分下界联合训练；推理可单独使用去雾网络。
- 启发：若声称“不确定性”或“物理可靠性”，需要明确的概率对象或独立校准证据。softmax 融合权重只表明网络的选择，不能直接获得这种解释。

补充：遥感 [PhDnet 作者仓库](https://github.com/colacomo/PhDnet) 提供 Information Fusion 2024 论文及摘要信息，结合散射、残差雾提取和门控。本次仅核对作者摘要，未将其作为已完成全文分析的文献。

## 与本项目实现的对应

当前代码 `src/models/haze_density/calibrated_prior.py` 中，三张原始线索为：

1. D：局部暗通道。
2. C：灰度像素与局部均值的绝对差取负，属于局部对比度线索，不是局部方差。
3. K：`-(|R-G|+|R-B|)`，属于颜色差异线索；**不能称为经典 Color Attenuation Prior**，后者涉及亮度、饱和度与深度关系。

因此，“三先验”不是一个固定的标准三件套。论文应先准确界定本项目先验的假设与有效范围，避免借用不对应的物理解释。

当前模型对已标定 H 候选做非负、和为 1 的融合：

`H_hat(x) = sum_k w_k(x) P_k(x)`，`w_k >= 0`，`sum_k w_k = 1`。

这意味着输出必在候选最小值与最大值之间。该性质只约束这种输出级融合，不代表所有先验引导网络都有同样上限。特征融合、候选校正、散射约束是不同机制，不能用一个凸融合模型的失败否定全部先验路线。

反过来，换成特征融合也不能自动解决本任务：表达力变大可能只等于另一个 RGB 回归器，需要先验移除、无效先验替换、匹配参数与计算预算的对照，判断先验是否确有贡献。

## 收敛到一条研究问题，而非继续堆分支

建议保留三先验方向，将候选主线收敛为：**面向遥感雾强度估计的三先验偏差诊断与受约束校正**。

论文差异若成立，应体现在下列可验证结果，而非模块名称：

- 将地物亮度/纹理带来的响应与 H 目标区分，明确哪些情况下每种先验及三者共同失效。
- 校正改变候选估计本身，并实证减少共同偏差和不可达区间误差；不是用空间权重掩盖候选问题。
- 在冻结候选后单独测量动态融合的增益，让“校正收益”和“选择收益”能够归因。
- 在独立场景和匹配信息/完整成本下，说明相对直接 RGB 回归的具体价值。

这些是后续论证标准，尚不是已有创新结论。语义只是内容条件的一种候选来源；目前的冻结语义代理证据不足以让它成为必选模块，更不能将 RGB 派生语义称为独立观测。

如果校正无法优于总体标定，或三先验在相同成本下没有可重复的精度、泛化或稳定性价值，就应保留负结果并调整论文定位。现有证据只否定具体尝试，尚不足以支持“整个三先验方向应放弃”，也不足以保证这一主线一定能形成论文。
