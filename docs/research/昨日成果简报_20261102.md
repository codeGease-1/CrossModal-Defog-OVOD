# 2026-11-02 成果简报

我们做出了一版能与小型 RGB 回归竞争的受限候选校正模型。结论目前只覆盖反复使用的程序化开发场景，不能当成真实遥感或新确认成绩。

## 做了什么

有雾 RGB → 暗通道、局部绝对对比度、RGB 颜色差异 → 分别校正三个候选 → 固定或动态凸融合。

校正网络读取 RGB 以及亮度、纹理内容特征，对各自先验做有界变换；不直接输出自由 H 残差。H=1-t 表示合成协议下的有效遮蔽。这里没有地物语义分割，也没有新的物理约束。

## 新意在哪里

1. 把“候选本身一起偏了”与“权重没选好”分开处理：先校正候选，再检验融合，保留每张候选的独立成绩。
2. 采用受限、有原先验保留路径的校正方式，并让最终融合误差参与训练。开发结果说明这种限制下仍有竞争力。
3. 用同一套冻结候选比较固定融合、正常动态权重、均值权重和打乱权重，得到空间选择有效的直接证据。
4. 同时报告同训练配对/机会的 RGB 控制、离线凸融合下界、共同错误和完整推理成本。

这些是本项目拟检验的组合贡献和实验设计，尚不是文献首创结论。“三先验”“校正”“内容解耦”“独立透射率监督”本身不宣称首创；三先验不可替代性与同构辅助监督公平仍待进一步控制。

## 效果如何

相同训练配对和 36 轮训练机会，三个种子平均，非模型集成：

|方法|全部网络参数|像素 MAE|256×256 完整 GPU 耗时|
|---|---:|---:|---:|
|同骨干 RGB16|217985|0.009582|4.91 ms|
|同输入直接回归|219137|0.007693|6.45 ms|
|校正＋固定融合联合训练|218358|0.007990|6.60 ms|
|校正＋动态融合联合训练|221161|0.007261|7.31 ms|

联合动态模型较 RGB16 平均误差低 24.2%，参数多约 1.46%；较同输入回归平均误差低 5.6%。三个种子均优于 RGB16，但只有两个优于各自的同输入回归。

相对先前冻结校正，三候选共同低估超过 0.03 的比例从 1.87% 降到 0.25%，凸融合 oracle MAE 从 0.00483 降到 0.00192。固定同一批联合训练候选后，正常动态融合 MAE 0.007261，改为固定融合为 0.008641；权重均值化、打乱也会退步。oracle 只用于离线诊断。

## 还欠什么

- 完整推理比 RGB16 慢约 49%，参数接近尚不等于同成本。
- 未见大气光 MAE 0.079443，显示域混合压力 MAE 0.146140，均落后 RGB16。
- linear_srgb 表示在线性域加雾后转回显示 RGB；网络接收显示 RGB。压力测试改变的是加雾机制，不能靠简单逆 gamma 宣称解决。
- 没有新的真实遥感有效性、自然雾真值、新确认测试或独立物理贡献；优化损失结构与 RGB 控制仍有差异。
