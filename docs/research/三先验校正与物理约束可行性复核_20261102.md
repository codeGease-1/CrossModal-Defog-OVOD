# 三先验校正与物理约束：可行性复核

日期：2026-11-02。承接前述论文调研和两轮动态加权实验。本次补读 DehazeNet 全文，并完成一个 CPU 机制诊断；没有训练新模型、使用 GPU、改动历史结果、提交或推送。

## 判断

**保留“内容偏差校正”作为优先研究问题；物理响应作为有适用条件的约束与诊断；不把三张无雾基线的硬反演确定为最终结构。**

此前建议直接估计无雾基线再相除，低估了不适定性和误差放大风险。本次数学检查与数值诊断为这一限制提供了直接依据。方向有研究价值和实现路径，但论文创新、相对 RGB 回归的价值以及真实遥感有效性均未建立。

## 1. 问题确实存在，但原因不能过早归结为语义

历史第二轮实验已有三点直接证据：

- 学生动态加权在受控新场景的像素 MAE 为 0.018005，优于优化固定融合的 0.019927，空间权重消融会退步。动态区域选择本身有作用。
- 同骨干 RGB 回归为 0.013596，完整推理更快，说明三先验约束的实际价值尚不充分。
- 原始 S 的 8 张样本中，平均 31.99% 像素的三候选共同低估至少 0.03；局部相关从固定融合 0.779843 降至动态 0.708832。

这些支持研究候选估计的偏差。它们没有证明偏差全部来自地物内容；成像协议、大气光和光谱目标定义差异也是已知因素。语义校正只应是其中一个可检验解释。

证据：[历史深入探索报告](../v2深入探索与学生重构验证报告.md)。

近期 arXiv 文献按所读版本讨论，不据此宣称正式发表状态或最新 SOTA。上述范围不是穷尽查新。

## 3. 单图内容基线没有唯一物理解

散射模型 `I=tJ+(1-t)A` 中，即使 A 已知，单张 I 通常也不能唯一确定 J 和 t。

以各通道均相同的常量图为例，A=1、观测 I=0.8，有两种合法解释：

| 清晰地物 J | 透射率 t | 观测 I | H=1-t |
|---:|---:|---:|---:|
| 0.60 | 0.50 | 0.80 | 0.50 |
| 0.75 | 0.80 | 0.80 | 0.20 |

两张观测完全相同，三个先验也相同，但 H 不同。网络只能依靠训练分布、空间上下文和额外可用信息选择统计上更合理的解释，不能普遍保证恢复真实基线。

同景多雾配对可利用已知训练监督减少混淆，不能把未知真实图像的逆问题变成唯一可辨识。由 RGB 计算的语义同样不能增加独立观测，更不能保证打破这个歧义。

## 4. 物理响应的适用条件不相同

假定标量 t、空间恒定且已知的正值 RGB 大气光 A，并在正确的线性域令 Y=I/A、X=J/A，逐通道除法、不裁剪：

`Y=tX+(1-t)1`。

- **暗通道**：`d(Y)=t d(X)+(1-t)` 需要局部窗口内 t 恒定，才能把 t 移出局部最小操作。
- **局部对比度**：`c(Y)=t c(X)` 也需要局部 t 恒定。透射率变化会与地物纹理共同产生响应。
- **当前点式颜色差异**：`k(Y)=t k(X)` 在 A 正确、标量 t 的条件下逐像素成立，不需要邻域 t 恒定。

这比笼统说三种关系适用条件相同更准确。若改成逐通道 t，或采用空间变化 A、非线性色调映射、裁剪等，关系需要重新推导/验证。现有幂变换、引导滤波与监督标定后的候选也不直接满足这些原始关系。

物理处理域与展示域必须区分：可以在已知协议下线性域计算物理统计，最后把 H 使用固定色标显示；不能把显示域像素直接当线性辐射量。对未知遥感影像，sRGB 反变换也不等于恢复了真实传感器辐射定标。

## 5. 本次已完成的 CPU 机制检查

实现：[audit_physical_feasibility.py](../../scripts/semantic/audit_physical_feasibility.py)。结果：[独立目录](../../experiments/physical_feasibility_20261102/README.md)。

- 使用既有开发集前 4 个原始程序化场景；没有调用新确认集或真实测试集。
- 256×256，沿用 15 像素窗口；t=1/0.6/0.4、gradient、blob、regions，两个已有 A，亮度固定 1，共 48 个源样本。
- 三种处理条件、三个先验，共 432 行诊断；CPU 约 12.11 秒，GPU 使用和训练步数均为 0。
- **清晰图、A、t 仅用于离线诊断**。这不是可部署模型，更不是新方法精度。程序化类别名称没有用作语义输入或监督。

### 5.1 理想公式成立，但不能据此保证估计成功

正确线性域、已知 A、已知清晰基线时，均匀雾三种原始响应关系的误差接近浮点精度；代码对适用情形最大残差 <1e-5 的检查通过。

这一结果只核验代数与实现。颜色差异在非均匀 t 下也通过检查，符合其逐像素关系。

### 5.2 对比度反演很敏感

硬反演形式为 `t_c=c(Y)/b_c`。在正确线性域的均匀雾样本中：

- 若仅要求已知基线 b_c≥0.01，可参与反演的像素平均仅 47.96%；其余像素不应默认为可靠。
- 在这些条件有效像素上，基线取真实值时 H 误差约 8e-7；人为给基线施加 +0.005/-0.005 的两个扰动后，裁剪到 [0,1] 的 H MAE 两方向均值达到 **0.13855**。

±0.005 是敏感性测试幅度，不是某个模型的实测基线误差；0.01 也是数值诊断阈值，不是验证过的可靠性门槛。这个结果说明直接相除可能对基线估计精度要求极高。

### 5.3 雾边界使局部公式失效

regions 的真值分界线附近，暗通道/对比度的原始响应 MAE 分别约 **0.13148 / 0.05845**，离开 15 像素窗口跨界范围后接近 0。单位是相应的 A 归一化原始线索，不是 H 误差，不可拿来与模型像素 MAE 横向排名。

这意味着局部雾变化本身会破坏关系；一味加强局部物理约束，可能损伤局部分布，恰是历史实验需要保护的能力。

### 5.4 成像域和 A 误差不能省略

- 同一批均匀雾样本，暗通道在正确域、已知清晰基线的硬反演 H MAE 接近 0；若在显示 RGB 上错误使用线性公式，则为 **0.13277**。这两者暗通道条件有效覆盖均为 100%。
- 在正确线性域，对 A 施加预先登记的 RGB 偏移 `[+0.02,-0.02,+0.01]` 并裁剪到合法范围，颜色差异硬反演的条件 H MAE 在全部模式平均约 **0.12038**。使用的清晰基线仍按同一估计 A 计算，故不是基线估计器失准造成的结果。

不同先验/不同处理域的条件有效像素集合可能不同；不以这些条件误差排名先验或比较模型。所有覆盖率和未裁剪误差也已保留。上述扰动只说明存在敏感性，不代表真实 A 误差的统计分布。

## 6. 对方法设计的约束

本次检查不支持立即启动“估计三张基线后直接相除”的完整训练。若继续，第一版应限制为一个候选校正器：

1. 每张候选由自身原始线索与紧凑内容条件进行受限标定，保留训练集确定的总体映射和收缩回退；不增加自由 H 残差或全局强度头。
2. 独立 H 数值监督是主目标。若使用辅助基线预测，必须有训练清晰来源的对应辅助目标，不能只靠最终融合损失给它物理名称。
3. 物理关系优先作为**适用条件内的前向响应一致性软约束**，或仅作离线诊断。例如检查原始 q 与 `F(1-P,b_hat,A_hat)` 的一致性，不在低信息位置直接做不稳定除法。
4. 约束区域/阈值必须在训练与开发集确定，推理的任何回退或条件判断只访问允许输入。不能用真实 t 或清晰基线作为推理掩码。
5. 必须和同容量、不加物理约束的校正器比较；若收益全来自额外 RGB 容量，就不能宣称物理结构有效。还应检查移除/替换原始先验后效果是否保持，以判断校正器是否绕过先验。
6. C、D 共用冻结校正候选；固定权重训练优化。动态融合是独立增益检验，不再承担纠正共同偏差的任务。

“软约束”不是保证有效的新技巧，而是本次诊断导出的数值设计边界。约束若只在训练合成协议内成立，不能宣称获得真实物理一致性；强度图更平滑也不能视为更正确。

## 7. 数据与论文可行性的实际边界

| 层面 | 当前判断 |
|---|---|
| 共同偏差问题是否存在 | 有历史逐像素证据 |
| 原始响应关系能否实现与检查 | 本次 CPU 诊断完成，适用与失效条件均明确 |
| 内容条件校正是否改善 H 候选 | 尚未验证；既有语义试验全部回退总体映射，不提供正证据 |
| 物理约束是否优于普通条件标定 | 尚未验证，必须同预算消融 |
| 校正后动态融合是否有额外收益 | 尚未验证 |
| 是否优于同信息、同训练机会的 RGB 回归 | 尚未验证，历史对照更强 |
| 真实遥感泛化与独立 H 评价 | 现有数据资格不足以闭合 |
| 明确创新性 | 有候选差异，未完成充分查新和实验证明 |

程序化数据适合结构与机制初筛。真实背景上的已知追加合成雾只能证明该退化协议下的表现，不能代表自然雾的绝对透射率。原景分组、新留出场景、可靠目标和困难地物评价仍需闭合。

语义建议保留为可选条件，但不作为第一版必要项。此前测试的通用分割器在雾下不稳定；语义类别也无法精确提供纹理幅度或材质反射率。只有它在有雾开发场景可靠、并改善候选/融合下界时，才有理由纳入；直接回归应获得同样信息。

## 8. 有限验证与停止条件

接下来若获新增训练预算，先验证一个 C 校正器，不扩大门控搜索。预先登记三项主要判断：

- **候选是否变好**：逐先验误差、共同偏差、融合下界、清晰响应；同时报告包络外频率和幅度，防止仅扩大候选范围。
- **物理约束是否有独立价值**：在同容量校正器上，以开发数据确定的设置比较有/无约束；评价需包括协议外条件和局部能力。
- **是否值得保留三先验**：公平直接回归获得相同输入、训练配对与辅助监督机会，并比较完整成本。

核心通过后，才评估同候选 D 的空间收益。若校正没有减少共同误差或融合下界，或它只是更大的 RGB 回归器，不继续通过增加模块维持原主张。若 C 有益而 D 无益，可据实保留固定融合。

训练数据或辅助监督改变时，旧 A/B/RGB 成绩不是新的公平对照；需把重拟合/重训成本另计。原 1 GPU 小时是累计预算，本次没有新增训练授权，CPU 检查不占用该 GPU 额度。
