# 三先验论文主线重新评估

日期：2026-11-02。目标：形成有明确创新点的论文。本文为方法设计与取舍记录，未实现下述新模型，未开展新训练，未证明创新性或效果。

## 推荐的一条主线

**学习三先验在不同雾强度下的响应，估计并校正地物内容造成的偏差，再独立检验动态融合。**

拟议研究题目：面向遥感雾强度估计的三先验内容偏差校正与融合。

核心可检验假设：直接把低纹理、低色差和高暗通道等同于浓雾会产生内容偏差；若能显式估计这些线索的无雾基线，并按照成像响应关系构造 H 候选，就可能比总体标定更好地减少候选共同失效。校正后动态融合是否有收益是另一个问题，不作为预设结论。

三先验仍是主干；物理响应关系和训练期同景多雾监督是优先结合的内容。语义仅是可能的条件信息来源，当前已测语义未通过筛查，不纳入第一版必要依赖。

## 为什么这样选

| 做法 | 判断 | 原因 |
|---|---|---|
| 三先验后换更复杂注意力或门控 | 可用作实现，不适合作为主要贡献 | PGH²Net、DPSF-Net 等已有很近的机制；无法纠正当前候选的共同偏差 |
| 按语义类别做单调标定 | 有价值的低复杂度基线 | 已测来源不稳定，且条件标定本身不足以证明新意 |
| 先验的无雾基线与成像响应约束 | 本轮推荐验证的核心 | 直接针对内容混淆；每张候选仍可独立评价，能检查网络有没有真正校正先验 |
| 增加 NIR 或多时相参考 | 需另立数据资格与成本前提 | 现有任务尚未证明推理可获得这些观测，不能作为当前默认条件 |

上述新意判断来自代表性文献比较，不是完整查新或录用保证。

## 方法怎样落地

### 1. 明确要校正的量

当前代码中有暗通道 d、局部绝对对比度 c、RGB 颜色差异 k。为了推导，用 c、k 的正值，而非当前代码中“高值表示多雾”的取负版本。训练集固定标定保留；不对测试图逐图拉伸。

散射模型为：

`I = t J + (1-t) A`。

在标量透射率、局部窗口内 t 近似恒定、A 空间恒定、线性辐射域等条件下，若大气光为灰色 a，有：

`d(I) = t d(J) + (1-t) a`

`c(I) = t c(J)`

`k(I) = t k(J)`。

更一般地，若各通道 A 已知且为正，令 Y=I/A、X=J/A（逐通道除法，不裁剪），则有：

`d(Y) = t d(X) + (1-t)`，`c(Y)=t c(X)`，`k(Y)=t k(X)`。

这只是相应假设下的代数关系，不是新发现。实际推理的 A 必须从允许的观测获得；不得使用合成器或真值提供的 A 冒充可部署估计。新关系也不能直接套在幂变换、引导滤波或裁剪之后的历史候选上。

这些关系展示了当前偏差的来源：亮且近灰的地物可能同时具有较高 d、较低 c 和较低 k，三张原始线索都响应为“有雾”；这不是三张可靠 H 图之间的普通选择问题。

### 2. 估计地物本来的先验响应

从单张有雾 RGB 提取紧凑上下文，估计三种无雾基线 b_d、b_c、b_k，必要时同时估计低维 A。这里估计三种统计量，不输出清晰 RGB 图像，不增加自由 H 残差头。

训练期若拥有可靠清晰来源 J，可计算三种基线作为辅助监督。每个原始场景生成多个已知 t/A 的版本，要求同景不同雾版本的基线估计保持一致。若使用 J/A 形式，则基线一致性只适用于 A 相同的版本；跨 A 要先换回同一基准，不能错误强制它们相等。

推理只输入有雾 RGB；清晰图、t、场景身份和人工语义均不作为输入。训练阶段清晰基线辅助监督和原有旧教师评分蒸馏是不同的监督，必须分别记录来源与用途。

单图估计无雾基线仍然病态，尤其在厚雾中。低维输出和同景约束只限制模型自由度，不能保证分解唯一，也不能凭网络结构声称已辨识物理量。

### 3. 用响应关系生成三个 H 候选

在归一到 A 的推导形式中，可检查下列受约束候选结构：

`t_d = (1-d(Y))/(1-b_d)`

`t_c = c(Y)/b_c`

`t_k = k(Y)/b_k`

再得到 `P_j=1-t_j`。这是结构候选，不是当前已验证可用的具体实现。

重要风险：b_d 接近 1、b_c 或 b_k 接近 0 时，反演对误差非常敏感；三个候选可能同时缺乏信息。不能仅加一个 epsilon 再裁剪，制造数值稳定的假象。应先检查分母、噪声和 A 估计误差，采用训练集确定的收缩/总体映射回退，并记录失效覆盖率。

如果假设检查表明解析比值不适用，先停止该结构的完整训练；不能事后把任意 RGB→H 回归器包装为物理反演。普通条件单调映射保留为基线，但不足以单独支撑这一版方法主张。

### 4. 校正与融合分开

- C：冻结同一套候选校正器和候选缓存，训练集优化三个全局固定融合权重。
- D：候选与 C 完全一致，只训练三个 softmax 权重图。无自由残差、全局强度头或去雾分支。
- 校正器先依据各候选到独立 H=1-t 的误差及辅助基线监督拟合；不能只靠最终融合损失，让差候选隐藏在接近零的权重后。
- 门控权重表示融合选择；分母敏感性表示一种条件性诊断，二者都不是未经校准的物理可信度真值。

第一版重点验证校正器。D 若没有额外收益，可以据实保留固定融合；不以动态融合一定有效作为论文成立条件。

## 训练期如何避免把地物特征学成雾

优先使用训练原景内的交叉组合：同一 J 采用多个 t，同一 t 用于多个不同 J；亮度、大气光等变化也要避免与某个 t 固定绑定。先验基线监督和独立 H 数值监督为主，同景基线一致性为辅。

不同场景在已知、对齐的相同 H 条件下可比较绝对估计；未知真实雾图不能凭目视判断“同雾”，也不能无条件强制不同场景预测相等。非均匀雾中只比较已知同一目标位置/统计量，不盲目对齐语义特征或强行平滑地物边界。

同景多雾配对、内容解耦、物理一致性本身均已有文献先例。其价值应体现在对三种可解释候选的偏差校正上。

## 预期贡献与文献差异

| 最近的已有机制 | 拟议区别 | 仍需证明 |
|---|---|---|
| PGH²Net：多先验隐特征聚合 | 三张 H 候选在融合前有独立定义和监督 | 解释性与约束是否带来泛化价值 |
| DGFDNet：反馈修正暗通道引导特征 | 校正各先验的内容基线与绝对估计 | 候选误差和共同偏差实际改善 |
| PHATNet：分离内容与雾，用于雾迁移和域适应 | 不生成雾迁移图；用配对信息约束三先验响应 | 不是已有解耦方法的简单改名 |
| JSFD：三个统计特征加权估计密度 | 在独立 H 目标下校正各候选，再隔离融合因素 | 绝对误差、场景泛化及完整成本优势 |

最有希望形成贡献的组合为：明确量化三先验的共同失效；给出可被独立验证的候选校正结构；以独立场景、公平信息和成本证明实际价值。误差边界诊断是工具，不应单独包装成新理论。

## 最小、有限的论证链

1. **无新训练的资格检查**：在现有训练/开发来源上检验原始响应关系随 t、A、局部雾变化的偏离；排查 sRGB/gamma、窗口边界、裁剪、编码及实际数据域。这里只能证明假设覆盖，不能证明模型有效。
2. **获授权后的第一主要候选 C**：与相同数据上重新拟合的总体单调标定相比，候选误差、清晰响应、共同偏差及离线凸融合下界是否改善。包络外比例只反映频率，必须同时报告超出幅度；仅提高范围覆盖不代表候选更好。
3. **C 有价值后再验证 D**：同候选改变融合方式，测独立增益；动态权重塌缩和空间权重消融均需报告。
4. **第三主要新候选为公平直接回归对照**：获得相同训练配对、可用输入和辅助监督机会，计算完整参数与时耗；若加入派生语义，直接回归也获得同样语义。

旧 A/B/RGB 只有在数据、监督和协议一致时可复用为公平对照。改变训练来源、辅助监督或先验构造，应明确哪些控制组需重新拟合/训练，其成本另计。

校正结构还需有“去掉物理响应约束”的同预算校正器对照，区分额外容量与结构收益；在核心可行后纳入预先登记的必要消融，不作为启动更多模型分支的理由。

本轮新增 GPU 授权为零，历史余量不能自动用于该新方案。没有启动上述训练。当前程序化数据可用于初步诊断，不能承担真实遥感有效性结论；新留出场景、可靠独立目标和原景分组仍是论文实证前提。

若校正仅改变观感而不改善候选误差和融合下界，或优势在公平直接回归对照下消失，应否定相应主张。若 C 有益而 D 无益，保留“校正有效、动态选择无额外收益”的结论即可。
