# 地物语义辅助校正：本阶段实施与诊断

2026-11-01。独立目录：`experiments/semantic_calibration_20261101`。**实现及 CPU 诊断已完成；所测试的语义来源未通过稳定性筛查，不启动完整训练，不宣称语义有效。**

## 四个问题的回答

1. **语义是否可靠、能否改善候选及融合上限？** 本次冻结的 SegFormer-B0/ADE20K 不够稳定。6 张已暴露真实参考图在增加 `t=0.6` 的雾后，清晰输入高置信建筑/植被/水体预测区域的类别保持率为 **49.48%**，低于预先登记的 70% 门槛。它不是有标注语义准确率。程序化训练样本的有效类别覆盖又不足，最终全部回退总体标定；因此未观察到可归因于语义的收益。总体重标定改善部分候选，但凸包边界并未一致改善。
2. **校正后动态加权有独立收益吗？** 尚未验证。本轮实现了 D 并完成前向、凸组合、独立 H 反向传播的最小检查，没有完整训练 D。不能使用随机初始化输出或沿用旧 B 成绩回答 C→D。
3. **相同信息与完整成本下优于直接回归吗？** 无效果证据；CPU 推理成本也不支持优势。D 总神经参数 4,621,545、665 ms/图；RGB+相同语义直接回归为 4,620,647、408 ms/图。后两者未训练，这只是相同环境的计算图成本比较。
4. **收益在哪里、错误还剩什么？** 缩小协议下总体重标定主要改善暗通道候选的绝对偏差和清晰响应，与语义无关。植被预测消失、水体预测不稳、白屋顶语义覆盖不足、候选共同偏差和成像协议依赖仍在。没有支持真实遥感自然雾或跨地理泛化的新增证据。

## 冻结语义来源与失败证据

使用官方托管的 [SegFormer-B0/ADE20K 模型](https://huggingface.co/nvidia/segformer-b0-finetuned-ade-512-512/tree/489d5cd81a0b59fab9b7ea758d3548ebe99677da)，固定提交 `489d5cd81a0b59fab9b7ea758d3548ebe99677da`，3,752,694 参数，全部冻结，采用 safetensors 本地加载；权重、配置与哈希保存在实验目录。模型来自 ADE20K 通用场景语义分割，**不是遥感或有雾遥感专用模型**。其原始 150 类概率聚合为建筑、植被、水体及 other 四组；other 不具有明确地物含义，回退总体标定。512² 语义输入缩放、均值/标准差及输出插值均固定、记录在源码。此处是同一 RGB 的派生语义，不增加独立传感器观测。

初始开发探针为 6 张旧真实参考图与 4 个程序化开发场景，各检查 t=1/0.9/0.6/0.4。全像素在 t=0.6 时的高置信比例仍达 67.88%，但目标地物预测保持率只有 49.48%；**高置信不能证明预测正确或稳定**。G_1115 的植被参考预测保持率为 0，S_1282 的相应保持率约 0.004。G_1115 白色屋顶丰富，但清晰输入也很少被识别为建筑，缺少可靠屋顶标签，不能报告屋顶分割精度。

检查旧参考图接触表后，另在已暴露 G_1293/G_1297 上补充水体覆盖诊断，保留独立计划与结果，不改写原 6 图筛查结论。G_1293 顶部水面状矩形代理区中，水体预测比例由清晰输入的 44.52% 降至 t=0.9/0.6/0.4 的 0。该矩形是目视代理，不是人工真值掩码。失败图 `probe_external_G_1115.png`、`probe_external_G_1293.png` 使用一致类别配色。

仅凭本次筛查不能否定所有遥感语义方法；它足以拒绝直接为**本次已测语义来源**投入完整门控训练。

## 校正与融合的独立实现

新增 `semantic_prior.py`，不修改旧教师、学生或候选实现。

- 先验处理位置与旧 v2 一致：固定训练标定范围、逐候选幂变换/引导滤波，再对各先验分别拟合单调映射到独立 H=1−t；推理没有逐图 min-max。
- 总体与类别映射只拟合训练像素。置信阈值 0.6；类别至少 1024 个采样像素且覆盖 4 个训练原景；满足时按 n/(n+4096) 向总体映射收缩；低置信、稀疏类、other 均回退总体。
- C 只改变三个候选的估计值；固定权重在同一训练数据上用七个单纯形面的精确二次优化求解，包含像素 MSE、0.5×全图均值 MSE、0.25×条件清晰 MSE。
- D 使用与 C 相同的冻结标定与候选缓存，仅输出三个 softmax 融合权重；无残差、去雾、检测、全局头。候选缓存不含真值或清晰参考，逐文件 SHA256 清单已保存。权重仅解释为融合选择。
- 已实现 RGB+同一四通道语义的直接回归和 base8 轻量版本，保留 RGB-only 图结构用于成本参照。没有训练这些新网络。
- 五项契约测试通过，包含非训练集拟合拒绝、跨原景支持门槛、不确定/other 回退、oracle 投影、D 凸组合及一次 CPU 独立 H 梯度更新；随机模型仅用于实现检查与计时。

## 小规模标定与能力边界

本轮只做 **8 个程序化训练原景 × 4 种版本、4 个开发原景 × 4 种版本**的标定可行性诊断。固定一个大气光和亮度，保留清晰、t=0.6、gradient、regions；这是缩小的开发协议，不是历史完整协议或新的确认集。

训练采样中，建筑为 0 像素/0 景，植被为 291/3 景，水体为 3/1 景，均未过门槛。other 的 7423/8 景不构成地物类别证据。最终条件映射为空，**C 与总体重标定逐像素完全相同**。初版将 other 也作为条件类的开发试验留存在 `initial_other_class_trial/`：其像素 MAE 0.011601，反而略差于总体映射的 0.011557；最终 other 回退属于开发修正，没有访问新确认测试。

|---|---:|---:|---:|---:|
| 历史原候选，固定权重重新优化 | 0.017921 | 0.025479 | 0.970143 | 0.015788 |

另有标定表 162 个标量、固定权重 3 个。语义单独推理中位 200 ms，p95 227 ms。语义模型文件约 15 MB；诊断特征缓存约 177 MB，冻结候选约 71 MB；扩展水体探针的缓存增量以最终产物清单为准。一个进程同时加载所有对照时 CPU 峰值约 758 MB，**不能归因给某一方法**。本轮 GPU 未使用，逐模型显存与 V100 新图结构时延未测，不把 CPU 时间当 GPU 时间。

历史累计 3230.1896+28=**3258.1896 秒**，原 3600 秒额度算术余量 **341.8104 秒**。本轮新增 GPU 授权为 0，实用为 0；没有把一小时解释为每轮额度。

若后续明确授权且语义先通过检查，首轮最多 C、D、RGB+同语义三个主要新候选。以原 48/16 场景、每景 32 版本、18 轮、3 种子为具体规模，历史 D 类训练 1225 秒、RGB 类训练 1248 秒，共约 **41.2 GPU 分钟**；为新输入、验证、保存和评价建议另预留 **10–20 GPU 分钟**，追加需求约 **51–61 GPU 分钟**，不是已批准预算或实测承诺。新留出场景数量决定额外评价量。

可先在 CPU 预计算：2048 个训练/开发版本按本机完整 C 时间粗估约 **17.7 分钟**，不占新增 GPU；门控输入加目标的 float32 未压缩缓存约 **7 GiB**，实际压缩比例与语义来源有关。不要用模型下载时间或冻结模型成本为零来缩小估算。云实例费率未核验，不虚报货币价格，不购买或调整资源。

上述预算仅适用复用原协议。如果取得新的真实场景或改变监督/训练数据，A 的标定和固定权重、B 和 RGB-only 都必须在相同协议重新拟合/训练，控制组重训成本需要另计；不能把旧分数当公平对照。base8 对照仍需先满足相同信息与预算匹配条件，当前只有参数/计时，没有非劣效果证据。
