## 1. 最重要的研究判断

当前实现的是**先验伪标签监督的相对雾感图预测**。网络和先验的 MAE/RMSE 衡量规则拟合，无法独立证明物理雾浓度准确；也没有证据表明已提升完整 OVOD。整体项目名与当前子模块成熟度应分开表述。

源代码多处写“严格依据最终版申报书”，但工作区没有该 PDF。本次只能核对代码之间是否一致，不能背书其与申报书逐条一致，也不能把代码注释当作创新性证明。

## 2. 已修正的问题

| 问题 | 原来的影响 | 本次处理 |
|---|---|---|
| `min_max_normalize` 连续两次沿 `dim=2` 取极值 | `keepdim=True` 后第二次仍沿高度 1 维计算，实际按列归一化；水平方向变化可能被抹掉 | 第二次改为沿 `dim=3`，得到真正 `[B,C,1,1]` 极值；补横向梯度与批/通道独立性回归 |
| 无固定 split 文件时 train 直接使用全部官方 train | val 从同一批图片抽出，造成重叠，影响模型选择 | train/val 用同一确定性划分互补选择；任一首次加载都能保存 manifest；已有划分做交集与覆盖核验 |
| Dataset 划分重置全局 `random.seed(42)` | 数据扫描影响训练随机状态 | 使用局部 `random.Random(42)` |
| 非最佳轮的 `latest.pth` 写 `best_val_loss=None` | 恢复后格式化/比较失败，且丢失历史最佳值 | 每轮保存真实累计最佳值，恢复 scaler；新增回归 |
| CSV 只在训练结束时写出，恢复会覆盖旧日志 | 会话中断后丢失日志，难追踪实验 | 逐轮追加日志，恢复核对已有日志末尾轮数；禁止新训练覆盖旧实验 |
| YAML 与训练脱节 | 旧文档声称支持 `--config`，实际脚本未读取；深度、调度器等字段也未生效 | 新增 `--config`、CLI 优先合并与未知字段检查；精简为实际支持的平铺字段 |
| 评估总是使用先验默认参数 | 非默认先验训练与评估口径不一致 | 从 checkpoint 读取先验窗口/滤波参数，写入报告 |
| 先验变化未标记 | 修正后标签与旧 checkpoint 指标易混用 | 新权重记录 `prior_version=spatial_minmax_v2`；旧权重恢复被拒绝，探索性评估明确警告 |
| 固定评估目录残留旧图 | 新旧实验图可能混用 | 增加 `--output_dir` 并要求空目录 |
| 静态检查依赖输出目录存在 | 新 clone 即使源码齐全仍可能失败 | 只检查源码必需目录；补历史路径工具的语法错误 |
| `smoke_test.py` 仍是占位实现 | 只打印“待实现”却返回成功，容易被误认为模型验证通过 | 替换为真实小张量先验、前向、损失、梯度与优化步骤检查；缺依赖时失败退出 |
| 运行依赖缺少绘图库、Git 无忽略规则 | 数据检查可能缺依赖；数据和权重易误提交 | 补 `matplotlib`，忽略数据/权重/缓存，保留 split manifest；清理两份已跟踪字节码 |
| Markdown 路径、命令与状态过期 | 新手按文档找不到脚本，或把模板误认为已完成实验 | 重写首页、索引、状态、运行/Colab 指南；新增原理解读；历史阶段文档标记并修正脚本路径 |

## 4. 尚未解决、需要实验或后续实现的问题

| 事项 | 为什么影响研究结论 | 下一步 |
|---|---|---|
| 逐图 min-max 的相对性 | 分数不能直接跨图标定轻/重雾 | 引入独立雾等级或可核验物理量，研究归一化与标定 |
| 暗通道/灰度差/颜色差的场景歧义 | 白屋顶、云、雪、平坦地物也可能高分 | 做分场景人工检查、清晰负样本、先验消融 |
| 均值滤波边界零填充 | 边缘可能出现非真实对比度与评分 | 对照有效像素归一化或其他 padding；变化需另记标签版本 |
| Decoder 输出前 InstanceNorm | 限制单图评分分布，绝对幅度表达受约束 | 做移除/替换的架构消融，不能静默改旧权重结构 |
| `return_clean=True` 且使用随机训练增强 | hazy/clean 各调用一次随机变换，可能错位 | 当前主训练未使用 clean；未来成对恢复训练前实现同步几何变换 |
| 固定 manifest 只核验样本键 | 不证明不同文件内容无重复或相邻裁块独立 | 结合内容哈希、原始场景/地理分组检查泄漏 |
| 断点恢复未保存 RNG/DataLoader 状态 | 无法保证与不中断训练逐位一致 | 若需严格复现，保存并恢复相关随机状态与环境版本 |
| 评估汇总与可视化 | 全量张量占 CPU 内存，图像为遍历前若干张 | 后续做流式统计与分层固定抽样；当前报告注明口径 |
| 只有集成原型、无真实下游任务 | 不能证明去雾/检测/分割收益 | 先选检测或分割任务，再做 RGB/直接先验/网络引导对照 |
