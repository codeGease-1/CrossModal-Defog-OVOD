# 阶段 2 评测方案审查

日期：2026-10-21；基于 `codex-v1` 阶段 1 完成后的代码。评测代码独立放在 `benchmarks/haze_density/`，不修改模型、先验参数或训练目标。

## 已确认与限制

- 输入是 `[B,3,H,W]`、0～1 的 RGB，输出是 `[B,1,H,W]` 的相对雾响应；约定越大表示越浓。三先验生成的图只作被评价方法，不能作为独立真值。
- 当前先验版本为 `spatial_minmax_valid_boundary_v3`；项目阶段名称 V1 与内部先验版本 v3 是两个概念。
- 本地仅有未记录先验版本的旧权重，不能当作 V1 学生网络结果。本地无 RSHaze+；VS Code 的 Colab/Jupyter 内核不等于本聊天具有远程执行通道。提供内核内可运行的独立入口，运行结果必须由该内核实际产生。
- 历史文档对 RSHaze_G/L/S 的解释和规模存在矛盾，不能把这些目录名直接当作轻/中/重雾等级，也不能凭 `transpng` / `airpng` 文件名认定真值可信。

## 评价定义

1. **独立合成参照**：真实清晰遥感场景上使用 `I=J*t+A*(1-t)`。默认将显示 RGB 按 sRGB 近似解码到线性域，在线性域调整亮度、加雾，再编码回显示 RGB 供原算法读取。保存 float32 的清晰图、输入、t、A 与参数；PNG 仅供预览。普通显示 RGB 缺少传感器响应和辐射定标，结论限定为受控成像实验。
2. **独立划分**：场景清单明确 `scene_id/group_id/split/land_cover/source`。原场景及其裁块/变体必须共享 group 和 split；按内容哈希拒绝跨集合重复。禁止按合成图片随机划分。土地覆盖来自人工或来源元数据，不根据亮度/纹理猜类别。
3. **最小闭环**：少量真实清晰场景、一个 A 和亮度、`t=1/.9/.75/.6/.4`；先运行原始未逐图归一化的暗通道响应与三先验融合，检查独立真值、排序指标和固定色标图。
4. **完整扩展**：梯度、团块、多区域 t；多个 A/亮度；按地物、A、亮度和雾场分层。方法为原始暗通道响应、当前三先验融合、有效 V1 权重的学生网络。缺少合格权重明确 `NOT RUN / NOT EVALUATED`。
5. **排序**：同场景、同 A、同亮度下，以平均预测评分比较均匀雾序列的 `1-t`；报告严格 pairwise accuracy、平局率、Spearman 和相邻强度单调性违反率。平局不算正确，相关系数对常量返回“不适用”，不替换成 0。
6. **空间**：与已知 `1-t` 比较固定网格区域均值的相关/排序、重雾与轻雾区域的预测差；另绘制维度无关的秩残差。均匀真值的空间相关“不适用”。不拟合物理映射，不计算未标定的物理 MAE。
7. **无雾与混淆**：记录无雾均值、分位数及固定参考阈值以上面积（只作响应诊断，不能跨方法当作统一 FPR）；用同场景强雾减无雾评分、排名和平局评价方向。附按清晰图定义的暗/亮/低纹理诊断区域，与地物标签分开。
8. **统计**：先每个原始场景内汇总，再做场景宏平均并报告有效场景数；同场景的多个变体不当作独立样本。小样本结果只作试验性证据，不包装成总体性能结论。
9. **性能**：256/512、batch=1、固定线程/预热/重复次数；分别计预放设备张量的算法时间，以及内存中 RGB 解码/缩放/转换/传输/前向/回传的端到端时间。CUDA 前后同步，报告 P50/P95、均值、吞吐、峰值 allocated/reserved 显存、参数量；MACs 若仅统计卷积/线性则明确为部分统计。无 GPU 记 `NOT RUN`。随机初始化网络只允许标成结构性能测量，不能产生正确性成绩。

## 状态与验收

`PASS/FAIL` 表示代码和数据有效性检查；算法指标本身为观测值，未预注册验收阈值时不随意宣布算法 PASS。`NOT RUN` 表示资源不足未执行；`N/A` 表示指标数学上不适用；失败运行保留错误信息。所有 JSON 禁止写入 NaN/Inf。

先完成最小闭环实际运行，再扩展；若拿不到真实场景，只能把生成图案用于实现测试，并明确真实场景评测尚未运行。所有实验保存配置、种子、源码哈希、Git commit/dirty、输入文件哈希和运行环境。实际结果与方法解释分开，失败案例的原因作为待验证假设。

真实数据部分核查作者发布资料与已有文件编码；没有可核验的参数语义、比例和重建证据时，不把外部辅助 PNG 纳入物理真值。RRSHID 等真实影像只按可证实的经验标签或人工盲评处理，预留标注模板。
