# v1.5 / v2 当前研究状态

2026-11-01。本页区分已实现的实验分支与后续设想；完整方法和限制以对应实验报告为准。

## 当前保留什么

- **保留强度信息的标定方向。** 新实验不对每张输入图重新 min-max，而由训练集确定固定尺度及到独立目标 H*=1−t 的映射。不能简单移除归一化后相加不同量纲的先验，也没有删除所有网络归一化层。
- **旧主流程和对照保留。** 旧教师、旧学生、旧权重不变。真实遥感标定与局部分布退步尚未解决，当前固定标定参数不能直接替换旧流程。这与继续采用保留原始强度的研究方向不矛盾。
- **保留动态加权实现及正负证据。** 重构学生骨干输出三个 softmax 权重，融合三个已标定候选图；从头训练，不继承旧学生权重。监督来自独立透射率，不再蒸馏旧教师的逐图归一化评分。没有自由残差、全局强度头、多模态、去雾或检测模块。

## 已有结果支持到哪里

相同新确认样本、三个训练种子的平均像素 MAE：优化固定融合 0.01993，重构学生动态融合 0.01801，同骨干 RGB 回归 0.01360。动态融合改善约 9.6%；把空间权重换成每图均值后 MAE 为 0.02051，支持区域选择有作用。

以上为受控合成证据。原始 S 样本的局部空间相关出现退步，不能宣布真实遥感任务已解决。RGB 对照当前更强，但也未满足全部真实数据要求。权重是融合选择，不是经过独立校验的物理可信度。

## 多模态加轻量门控：待验证假设

目标可以设为：较低的完整推理成本下，达到直接回归的预先约定性能容差，或获得稳定改善。当前没有这方面实验，不把目标写成成果。

1. 先明确额外信息是什么、推理时如何获得。由同一 RGB 推导的语义图属于派生信息；它不能凭空增加传感器观测。若使用冻结的大模型，需同时报告其总参数、耗时、显存和预计算成本，不能只报可训练门控参数。
2. 公平对照至少包含 RGB 回归、RGB+额外信息的直接回归、RGB 动态融合、RGB+额外信息的动态融合。另比较匹配预算的轻量 RGB 模型，区分信息、融合机制和模型大小的贡献；分阶段开展，不自动突破已有训练预算。
3. “接近”要在新确认测试之前，用应用需求确定非劣容差。沿用独立透射率目标、按原始场景划分、清晰响应及局部能力检查；旧确认集已被反复分析，只能用于开发参考，后续正式结论需要新的留出场景。
4. 若额外信息只改变权重，输出仍在三个候选值的逐像素包络内。三者共同偏差不能被权重消除；先检查关键错误区域是否具有可选择的正确候选，再决定投入。

达到公平条件下的性能与成本目标，能支持方法在已验证范围内的可行性；是否具有论文创新性仍需文献定位、消融和跨场景证据，不能仅由参数更少推出。
