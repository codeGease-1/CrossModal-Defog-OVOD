## 判断

校正动态相对校正固定改善9.82%，三个种子都改善；相对匹配原候选动态改善34.20%，所以两者有开发收益。
但相对同宽度纯RGB，误差仍高27.44%（场景bootstrap95%区间21.88%至32.39%）；相对同输入直接回归高58.74%（46.58%至71.48%）。远超5%容差。局部相关和清晰响应差在预登记容差内。

校正动态参数比纯RGB16多1.46%，完整GPU推理约1.87倍，PNG到CPU输出11.93ms对7.19ms。相对RGB32参数少74.5%，但误差高35%、推理仍更慢。完整成本目标尚未达到，不能只报小门控参数。固定标定常量和显存另见完整成本JSON。

## 机制证据

D/C/K误差由.01991/.13859/.12139降至.01329/.03232/.04334；共同低估超过.03的比例从7.42%降至1.87%，共同高估从1.80%降至.87%，oracle MAE从.00838降至.00483。包络越界比例却由32.66%升至48.43%，必须同时看幅度和oracle，不能单看覆盖率。

空间均值化门控MAE .01276，空间打乱.01323，正常.01221，说明确有空间选择。平均D/C/K权重约85.8%/10.3%/4.0%，不能凭低平均权重宣称某先验无用。

新增17.12秒诊断：把同输入RGB预测投影到冻结候选区间，MAE由.00769变为.00953，当前门控.01221，oracle .00483。候选范围与融合学习均有损失，不能把二者误差差值当成严格因果分解。投影组合两套网络，仅作诊断，不是公平部署模型，也不保证门控可学到。投影不使用真值；oracle仅离线使用真值。

## 下一步，按顺序收敛

1. 先审计推理成本并做数学定义不变的等价优化。先验提取实测3.86ms；共享引导滤波统计、向量化单调映射、重复校验同步值得检查。固定FP32先验与AMP网络，不删步骤换成绩，先通过数值一致性再计时。所有使用先验的对照都享有同样优化，不能预设一定追上纯RGB。

2. 若继续结构研究，限两个新候选检验“冻结与目标错位”：受限校正器配固定融合、受限校正器配小动态门控。第二阶段允许联合更新，用最终H任务损失加预先固定的独立候选辅助损失。无自由H残差、不扩大骨干、不加语义或物理。从原18轮校正开始追加18轮，与RGB36轮对照；数据、训练机会或监督一旦改变，必要控制同步重训。两候选三种子预计25至35 V100分钟，待实测。这只是提案，尚未启动。

3. 相同参数及完整成本下仍超5% MAE容差，或收益不稳定，就停止这条结构的扩大训练。允许最终选纯RGB或精简先验；不能预设三先验必须保留。已有投影和oracle仅说明潜力，不构成继续加模块的效果保证。

4. 论文有效性阶段另行核验真实清晰遥感来源、地理分组、重复裁块、残余雾与编码；新协议重拟合并重训公平控制，冻结后才用新原景确认。程序化类别不是语义，真实背景追加雾也非自然雾真值。
