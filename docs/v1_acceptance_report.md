## 指标和数据核查

密度分数越大表示越浓，真值为 `1-t`。均匀雾严格按 scene、A、brightness 分组，五档强度每组十对，共 16 组、160 对，平局不计成功；没有跨背景、A、亮度误比较。当前每场景变体数相等，宏平均与计数比一致。

区域指标直接对固定 4×4 区域的预测均值与 `1-t` 均值计算平均秩 Spearman，没有用真值拟合或归一化预测。常量真值排除空间相关，常量预测相关 N/A、区域排序为 0。历史区域指标与 SciPy 最大差 `1.11e-16`；100 次/图的随机置换控制均值为 DCP 0.00647、三先验 0.00157，未见常量/置换后仍高分的退化现象。

历史空间模式在地理组内重复，模板简单；已知模板 oracle 不看 RGB 也能达到相关 1，这是协议局限。未发现真值进入 DCP/先验预测器；学生缺失，不能得出训练后无泄漏的结论。补充实验在渲染 RGB **之前**用 `SHA256('42:rotation:'+case_id) % 4` 旋转空间真值，预测器仍只接收 RGB，均匀雾保持原协议。

历史 128 个 NPZ 重算合成的最大像素差为 0，256 张预测的哈希及均值复核通过。真值来自指定 t，没有采用伪标签或含义未证实的 transpng/airpng。近似线性 sRGB 混合有记录，但不等于完整遥感辐射传输。

逐图 Min-Max 信息损失可复现：输入均值从 0.45 变成 0.68，归一化均值均约 0.5，最大图差仅 `2.98e-7`。正仿射幅值基本被消除；未做消融，不能将全部排序失败单独归因于此。本轮保留归一化、权重 `0.5/0.3/0.2`、指数 `1.5`、网络及 MSE。

## 工程、训练和归档

保留阶段 2 的真实 CPU 逐次延迟、P50/P95、吞吐；本轮没有将其当作 GPU 数据。学生结构 **864,752 参数**；256/512 的 Conv/Linear MACs 为 **13,957,644,288 / 55,830,429,696**，是部分算子计数，不是总 FLOPs。随机权重计时不能证明正确性。GPU 延迟、吞吐、峰值显存 NOT RUN，CPU 显存 N/A。现有计时包含预热、前后同步，区分设备驻留前向与解码/传输/回传端到端范围。

最小训练补齐方案（**未执行**）：

1. 准备真实数据与场景身份，按原始场景/地理组建立 train/val/test；需要物理映射时另留 calibration。同源雾变体必须共组，核对重复内容与相邻裁片。当前默认图像级随机划分只能证明路径互斥，不能充当场景隔离证明。
2. 确认划分文件存在且覆盖正确，禁止缺失时退回默认随机划分。从随机初始化训练当前 `spatial_minmax_valid_boundary_v3`，沿用 `configs/haze_density.yaml` 的结构、损失、`lr=1e-4`、seed=42、256 输入，使用新输出目录。
3. 经授权先做 **1 epoch 功能训练**，保存权重、划分哈希、配置、日志并跑独立 Benchmark；一轮不代表收敛。正式比较预先固定预算，按验证集选权重，可采用现有 50 epoch 配置，需另获长训练授权。不能利用已查看的测试结果调参，也不能修改旧权重版本字段冒充新训练。

最终联合 **73 项测试通过**，静态检查、小张量计算图检查通过；更新后的内嵌包另解压验证，见证据索引。Windows SciPy 与 torch 同进程发生 OpenMP 冲突，独立统计已改为子进程；未使用不安全的重复 DLL 放行选项，未改动安装环境。

seed=42、配置、清单、数据/权重/源码 SHA256 见 [验收证据索引](validation/v1_20261022/freeze_manifest.json)。执行日志的 HEAD 为起点 `03d7de9`，不能冒充最终工作区提交；最终审计快照用索引中的 Git 标签定位。随 Git 保存精简证据，原始数组及源码快照另归档于 `experiments/`，没有声称大文件已上传。
