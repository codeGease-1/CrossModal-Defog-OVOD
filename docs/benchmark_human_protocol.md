# 真实遥感雾强弱辅助验证协议

当前没有完成真实影像人工盲评，状态 NOT RUN。本文件提供标注格式，不将经验标签冒充物理参数真值。

[RRSHID 作者仓库](https://github.com/AeroVILab-AHU/RRSHID) 提供真实遥感有雾/去雾配对数据；[论文 IV-B](https://arxiv.org/html/2503.17966v1) 的雾强度分级依据 DCP 均值。因此，这种标签可描述数据集分层，却不是评判 DCP 或其融合方法的独立物理 Ground Truth。人工去雾参考图也不是 t/A 的测量真值。引用数量、协议时应核对版本，历史调研表不代表本次已获取或标注了数据。

小规模试验由协调者选择若干地理来源明确、尽量背景可比的图像对，固定显示范围、相同裁剪尺度，随机左右位置并隐藏模型名、模型分数、文件名和经验密度标签。至少安排三名独立标注者判断哪侧雾更重，允许相近和无法判断；重复少量图对检查同一标注者一致性。

记录字段模板见 [CSV](../benchmarks/haze_density/human_annotation_template.csv)。pair_id 到原图路径、地理分组、随机种子和左右映射的表由协调者单独保管，不能给标注者看；不收集姓名等个人信息。训练/校准/测试按源场景隔离，测试标注不参与阈值拟合。

分析时先报告标注者间一致性、无法判断率、有效图对数和各地物数量，再统计模型与多数意见的排序一致率。平局/不确定处理在看模型结果前固定，并单独报告，不能事后挑选一致图对。人工排序仅是感知参照；物理真值需独立的透射率、消光系数或观测仪器支持。不同背景图像对存在混杂，应与同场景比较分开报告。
