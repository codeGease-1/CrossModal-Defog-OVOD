## 确认结果与修复

| 核查项 | 确认的问题与证据 | 处理结果 |
|---|---|---|
| Min-Max 维度 | 本阶段开始时已经是先 `dim=2`、再 `dim=3`，极值形状为 `[B,C,1,1]` | 保留逐图、逐通道归一化；用横向梯度、多批次、多通道及单行/单列回归确认，不重复修改维度 |
| 局部均值边界 | 常量 0.5、3×3 窗口的角点均值为 0.222222，内部为 0.5；不存在的补零被计入分母 | 两处均值共用有效窗口实现，`count_include_pad=False`；角点恢复 0.5 |
| 引导滤波边界 | 引导图全零、源图恒为 0.5、半径 2 时，角点输出 0.1152，内部为 0.5 | 修正所有局部均值的分母后，整图保持 0.5 |
| FP16 除零 | `1e-8` 在 FP16 下变为 0，常量 Min-Max 出现 `0/0`，完整先验也产生 NaN | FP16/BF16 统计提升到 FP32；正则项设可表示的正数下限，默认数值不变；低精度输入返回 FP32 先验 |
| 常量图舍入误差 | 仅修正边界分母后，FP32 常量 0.3 的微小求和误差仍被 Min-Max 放大，`C_hat` 在约 0.019356～1 间变化 | 用等价式 `mean(x-reference)+reference` 求均值；常量差值精确为零，`C_hat` 恢复全 1；方差的负舍入误差截为 0 |
| 成对随机增强 | `return_clean=True` 时 hazy/clean 各抽一次随机裁剪与翻转，几何位置不同；缺失 clean 时还会返回不一致的键 | 同一对共用一次裁剪/翻转参数；要求同名文件、相同原始尺寸、完整 clean；自定义成对变换必须提供 `apply_pair` |
| 划分脚本 | 将官方 train 中与官方 test 同名的文件删除，丢失有效训练样本，并与 Dataset 的清单覆盖校验冲突 | 保留官方 train；原始路径键包含官方目录。train/val 仍严格互斥；生成划分使用局部 RNG，空数据/非法比例不写坏清单 |
| 检查脚本 | `check_data_leakage.py` 传入不存在的 `return_path` 参数而必定失败；旧验证器还把不同官方目录的同名文件判为重叠 | 修正 API 调用，只读元数据检查 train/val/test 路径复用；验证器拒绝重叠、内部重复、空清单及不支持的旧格式 |
| 非法输入 | 空张量、错误通道/维数、NaN/Inf、越界图像及非法窗口/正则项可能继续传播或出现底层异常 | 在先验/滤波入口明确拒绝，不静默替换图像或标签 |

边界修改依据是“窗口内实际像素的均值”语义，以及引导滤波对常量源图的保持性质；原论文的局部统计量与归一化滤波核见 [Guided Image Filtering](https://people.csail.mit.edu/kaiming/publications/eccv10guidedfilter.pdf)。这次纠正的是 padding 被误计入均值分母，没有通过实验挑选 reflect/replicate 等扩展策略。暗通道的负 max-pooling 边界不会引入虚假黑像素，白图测试已确认，因此保留。

当前主训练只读取含雾 RGB；伪标签在裁剪/翻转之后，从同一个张量实时生成，未发现该路径的图像/标签错位。clean、透射率、大气光和 NIR 没有被加入密度损失。

## 保持不变的设计

保留原始暗通道、灰度均值残差、颜色差异公式，逐图 Min-Max，融合权重 `0.5/0.3/0.2`，指数 `1.5`，默认窗口 `15`、引导半径 `15`、正则项 `0.01`，以及整个网络结构和 MSE 训练目标。数值修复没有引入近常量阈值或重新标定分数。无色常量图在原公式下应得到约 `0.353553`，并不因此变成物理意义上的“零雾”。

## 对已有训练权重的影响

先验版本更新为 `spatial_minmax_valid_boundary_v3`，新训练配置的输出目录改为 `spatial_v3`，避免混用旧实验。旧权重没有被改写；网络参数名称、形状和训练损失保持不变。

对本地 `experiments/haze_density/checkpoints/best.pth` 实际执行了 `torch.load(weights_only=True)` 和严格 `load_state_dict`：全部键匹配。黑图、0.3 常量图、白图的小尺寸前向输出均有限且形状正确。这只验证结构与运行兼容，不证明旧模型适合新标签。

边界和数值修复会改变伪标签；无版本记录或 v2 的 checkpoint 不应作为同一次 v3 实验继续训练。恢复入口拒绝版本不符；探索性评估仍会警告并记录训练/评估先验版本。旧指标不能直接与 v3 成绩比较，也不能通过修改版本字段把旧权重视为重新训练过。
