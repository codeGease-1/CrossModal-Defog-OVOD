# 近似局部均值：独立执行优化审查（2026-11-03）

此文补充 [当天主报告](optimization_results_20261103.md)。原严格等价审查未通过的结论保持不变；此处评估的是独立的近似数值实现，没有把原门槛放宽后改称等价。默认推理入口仍为精确 CUDA 捕获。

## 单独登记的质量要求

在计算像素 MAE 前登记：原执行相比，MAE 相对增加的旧开发场景 bootstrap 95% 区间上界 ≤0.1%，局部相关平均下降 ≤0.001，清晰响应平均增加 ≤0.0001。检查三个模型、三个旧条件、种子 42；只用于近似执行的小规模开发审查。原先的 1e-6/1e-5 特征/预测数值一致性门槛仍然失败。

三模型三条件通过上述质量门槛，最差 MAE 相对区间上界为 0.000085%。最大单像素输出差为 0.000488281，不能说输出不变。该结果没有覆盖所有训练种子、任意场景或新 A 增强权重。

256×256 的校正模型相对公平优化后的 RGB16 仍慢 41.5%。网络参数没有改变；只是使用可分离局部均值和 CUDA 图。近似执行并未完全解决“同完整成本”的目标，不以 PNG 解码开销掩盖 GPU 差距。

窗口均值用先横向、后纵向平均替代二维平均，保留边界分母规则和参考像素中心化。实数代数等价，但 FP32 累加顺序变化，经标定和 AMP 网络后产生不同输出。这个工程优化不是新的物理约束或新的语义贡献。

## 实验取舍与下一步

本次 A 增强使联合模型 unseen_A MAE 0.079443→0.028371，nominal 则 0.007261→0.032748；RGB 同样出现取舍。旧权重继续保留作为名义域主参考，A 增强版本只是试验权重。下一步优先检验固定配对数量下混合原 A 与随机 A 的保留训练，并加入名义域损失守门；三种架构必须获得完全相同的数据和机会。从旧 best 重启，避免把当前偏移后的权重当成新的公平起点。此建议尚未执行。

后续训练前还需判断 A/t/内容混淆的不可识别性与校正器限制，不能保证仅靠混合就解决。执行层面的剩余差距主要仍需继续测先验、内容特征与小输出头，不先新增语义、自由 H 头或硬物理反演。
