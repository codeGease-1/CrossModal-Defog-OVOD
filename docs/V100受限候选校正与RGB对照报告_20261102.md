## 可审查的候选校正结构

输入只有有雾 RGB。旧 v2 的训练固定总体映射生成三张候选 P；原始 D、局部绝对对比度 C、点式 RGB 差异 K 的定义保持不变，K 不是经典 Color Attenuation Prior。旧固定范围、幂变换、引导滤波和总体监督标定都保留，因此本轮与“旧候选＋重新优化固定融合”可以在同一协议下比较。

两个显式内容特征为有雾亮度的 31 像素局部均值及局部绝对偏差均值。它们不是地物语义，随雾变化，不具备可辨识的内容/雾解耦含义。StudentWeightGate 同族编码器提取 RGB 空间特征，宽度为 16；卷积头根据这些特征、RGB 和两个内容通道，产生每个候选的增益 a 和偏移 b：

`P'_k = 0.25 P_k + 0.75 sigmoid(a_k logit(clamp(P_k,1e-4,1-1e-4)) + b_k)`，其中 `0.5≤a_k≤2`、`|b_k|≤3`。

初始 a=1、b=0，近似恒等；每张输出只变换自己的候选数值，不能通过融合权重替换校正。保留 0.25P 的直接路径，系数固定时关于自身候选严格递增；RGB、内容也随输入变化，故不宣称整个系统具有这种全局单调性。不存在自由 H 残差、全局强度头、语义、去雾或检测分支。边界 clamp 使 P=0/1 时恒等误差不超过 7.5e-5。

校正器有 **218,358** 个可训练神经参数，全部用于推理。总体标定保存 362 个已拟合坐标/范围标量，固定融合另有 3 个权重，合计约 **218,723** 个拟合标量。不能仅报输出头参数。无自动支持区回退网络；第一版神经校正采用受限变换及固定 25% 总体路径收缩，域外不保证可靠。此前 CPU 表模型的支持区回退实现仍单独保留。

训练每个候选到同一个独立目标 H*=1−t，损失为 MSE＋0.5×全图均值 MSE＋0.25×清晰样本额外 MSE，三候选损失权重为 [1,0.25,0.25]。这明确偏重 D，而不是无差别证明三先验均有贡献。开发集选择 checkpoint 后，冻结校正器，在训练集上重新优化一组空间恒定凸融合权重。未增加动态融合模块。

必要契约检查通过：初始化、系数范围、梯度、输出范围、各候选依赖隔离及对自身候选的单调性。CUDA 实际保存/恢复模型、Adam、AMP scaler 和随机状态后下一步参数最大差为 0。训练输入缓存只有 RGB 派生的 11 通道，目标在独立张量中；清晰图、真实 t/A、场景身份与离线 oracle 均不进入 forward。校正器使用其中 RGB3、候选3、内容2，原始标准化线索3供同信息直接回归对照使用。

## 数据、对照及冻结纪律

仅使用已审查的 48 个程序化训练原景、16 个开发原景，256²；每景 32 个亮度/A/雾版本，分别为 1,536/512 个配对。同景所有版本同组；总体映射和融合拟合只用训练集。没有把程序化类别当真实语义，没有把真实背景合成雾称为自然雾真值。

正式轮三个主要模型，种子 42/43/44，每个 18 轮、batch8、Adam(lr=0.001)，网络统一 AMP，先验与目标 float32。所有模型使用相同训练配对、数据顺序规则、全图/清晰损失与开发选择规则：

| 模型 | 神经参数 | 输入与输出 |
|---|---:|---|
| corrector16＋固定融合 | 218,358 | 受限候选变换，冻结后拟合 3 个全局融合权重 |
| direct_same16 | 219,137 | 同族宽度16，所有相同的11通道 RGB 派生输入，直接回归 H |
| rgb32 | 867,377 | 同族宽度32，纯 RGB，直接回归 H |

三者都得到同一独立 H 监督，没有旧教师评分或额外清晰监督。原始候选＋优化固定融合也在同一训练集重新拟合。本轮未重训原始/校正候选的动态融合；历史动态成绩仅作先前证据，不能冒充本轮公平对照。FP32 单种子开发试验另存 `run01`，其小 RGB＋内容对照不同于正式 `direct_same16`，不得与正式轮合并平均。

新确认集预先登记 24 个原景，种子 22261101…22261124；与 20 份历史清单中的 113 个原景 ID 无交集。训练、开发拟合与 checkpoint 选择完成并保存源码、配置、9 份 best 及融合权重哈希后才生成新确认版本。包含 nominal、未见 A、display_rgb 三条件；后两者用于域偏移失败诊断，确认后不调参。

场景 bootstrap 固定三个训练种子，先对每个场景的雾版本和三个种子平均，再重采样 24 个原景 10,000 次。区间反映原景抽样不确定性，不能覆盖所有优化种子和生成器设计不确定性。局部相关只在目标有空间变化的版本有定义，清晰响应只在 t=1 版本统计；不把每像素当独立样本。

## 物理约束边界

本轮正式神经模型物理约束关闭。前一版 CPU 入口保留有/无前向软项对照，但精确合成关系下该软项化为监督平方误差的响应敏感度重加权，不能据此声称独立物理信息。

物理公式只在正确线性域、正确正值空间恒定 A、标量 t 下成立：`d(I/A)=t d(J/A)+(1-t)`、`c(I/A)=t c(J/A)` 还需要邻域 t 近似恒定；点式 `k(I/A)=t k(J/A)` 不需要邻域 t 恒定。不得把这些公式直接套到幂变换、滤波或标定后的候选上。本轮没有预测清晰基线后相除，也没有向推理注入真实 A、t 或适用掩码。未知 A、显示域和局部雾边界仍是实质风险。

## 结果与诊断

以下为冻结后首次生成的 24 原景、每条件 768 个版本，三个训练种子逐模型评价后求均值，**不是三模型集成预测**。主对照固定为 RGB32，完整数值见 `numeric_summary.json`、`analysis_confirmation/comparison.json` 和逐例 CSV。

| 模型 | nominal 像素 MAE | 全图均值 MAE | 局部相关 | 清晰响应 | 未见 A 的 MAE | 显示域混合 MAE |
|---|---:|---:|---:|---:|---:|---:|
| 原候选＋优化固定融合 | .019812 | .016637 | .976449 | .004621 | .084155 | .163898 |
| 校正候选＋优化固定融合 | **.013415** | .010590 | .977116 | .005497 | .079298 | .154605 |
| 同容量同输入直接回归 | **.012471** | .008799 | .977188 | .005455 | .068917 | .143395 |
| 纯 RGB32 | .014010 | .011096 | .977150 | .004225 | **.057317** | **.133098** |

nominal 下校正器相对 RGB32 的 MAE 差为 **−4.245%**，95% 场景 bootstrap 区间 **[−8.705%, +0.029%]**，上界低于 +5%。局部相关下降 .000034，区间 [−.000579,.000674]，上界低于 .01；清晰响应增加 .001272，区间 [.000425,.002178]，上界低于 .005。三项均通过本次登记容差，但 MAE 区间跨零，不能宣称统计上优于 RGB32。

这种结论只针对固定三个种子的均值。逐种子 MAE 如下，不能隐去优化稳定性问题：

| 种子 | 校正固定融合 | RGB32 | 相对差 |
|---|---:|---:|---:|
| 42 | .012532 | .014183 | −11.64% |
| 43 | .014762 | .012464 | **+18.44%** |
| 44 | .012951 | .015383 | −15.81% |

相对同容量同输入直接回归，校正器 MAE 约高 **7.57%**。直接回归也使用总体标定及全部 RGB 派生通道，故不能把“少参数接近 RGB32”全部归因于受限校正结构。正式轮只比较相同 18 轮预算及开发选择，没有证明 RGB32 的最优超参数或充分收敛上限。

### 候选是否真的变好

下表为 nominal 候选独立指标；校正列平均三个种子，不以融合低权重掩盖 C/K 的误差。

| 指标 | 原候选 | 校正候选 |
|---|---:|---:|
| D / C / K 候选 MAE | .019708 / .138490 / .120526 | .013174 / .032239 / .042587 |
| D / C / K 有符号偏差 | −.002029 / −.000916 / −.000897 | −.002434 / +.007703 / −.003025 |
| 三候选共同偏高至少 .03 | 1.605% | .889% |
| 三候选共同偏低至少 .03 | 7.424% | 1.791% |
| 真值超出候选范围的像素 | 32.805% | **49.187%** |
| 范围外像素平均距离 | .025488 | 约 .00993 |
| 离线逐像素凸融合 MAE 下界 | .008361 | .004870 |
| 离线逐像素凸融合 MSE 下界 | .00061767 | .00011469 |
| 最大范围外距离 | .369822 | **.475450** |

因此本版神经校正确实学到了减少共同大误差的能力，不是把 CPU 表标定的负面结果重复成路线否定。与此同时，包络覆盖率反而降低，最坏像素误差增大；校正使多数估计更接近目标，却没有解决尾部失败。oracle 只是候选区间到 H* 的投影距离，没有进入训练输入或推理。

nominal 的同景均匀雾排序和跨景均匀强度比较均达到 100%，四类模型都如此，说明当前生成器的排序任务过易，不能用它区分优劣。显示域条件下校正器同景排序约 98.96%、跨景约 96.06%，其全图数值误差仍很大；相关或排序较高不代表强度标定正确。

训练固定融合的 D/C/K 权重分别为：种子42 `[.96291,.03709,0]`，43 `[.91684,.05351,.02965]`，44 `[.94934,.05066,0]`。原候选为 `[.99009,.00991,0]`。主要贡献仍来自 D，K 在两种子中完全不参与最终输出；尚无证据证明三个候选都必要。

### 内容空间作用及域外失败

冻结后的开发推理干预选种子43，选择依据是开发集独立候选加权损失，而非确认结果。其正常 MAE .014968；把增益/偏移场均值化后为 .029086，打乱空间位置后 .037560，替换为整图均值候选后 .039652。说明本模型使用了空间系数和候选空间信息；这是推理干预，不能代替移除某先验后重新训练的必要性消融。

使用程序化清晰原图离线定义亮区 `gray>.8`、低纹理 `|∇gray|<.01` 两类代理，仅作诊断，不是地物语义，也不进推理。种子43的亮区三候选 MAE 从 [.04205,.21325,.16563] 降至 [.02611,.04084,.04907]，低纹理从 [.02047,.15699,.11829] 降至 [.01559,.03478,.04203]；但低纹理 D 的偏差由 −.00420 变为 −.00943，说明平均误差下降仍可能伴随局部偏差加重。语义失败的已有 SegFormer 证据原样保留，本轮无语义输入，不能声称收益来自语义。

未知 A 条件下，相对 RGB32 的 MAE 高 **38.35%**，区间 [31.44%,46.27%]；共同低估由原候选 36.73% 进一步增至 50.08%。显示域混合条件相对高 **16.16%**，区间 [12.73%,19.37%]；共同低估由 46.92% 增至 72.16%，oracle MAE 下界由 .07680 恶化为 .11739。这些条件未通过停止门槛，不追加模块或扩大训练掩盖失败。

复用此前 8 张已暴露、保守归为一个地理组的 S 样本与 PASS 编码检查，仅在冻结后做辅助失败诊断。目标仍为 `H_eff=1−mean_RGB(t_c)`，不改称标量物理 t。原固定融合 MAE .13327，校正器 .11782，同输入小回归 .09407，RGB32 .08121；局部相关分别 .77984/.78287/.66153/.70632。校正优于原融合但明显未接近 RGB，且不同评价指标结论不同。该端点没有独立地理组置信区间，不是自然雾真值或新确认集。

## 研究判断与停止条件

工程目标与论文贡献分别判断：受控协议内的小模型性能即使达到容差，也不能自动证明三先验均必要、内容已解耦、物理约束有效或自然遥感适用。PGH²Net、DGFDNet、PHATNet、JSFD、DehazeNet 等既有工作按研究记录定位；“三先验”“校正”“内容解耦”“独立透射率监督”均不能单独宣称首创。

若各候选误差、共同错误和离线凸融合下界不能一起改善，则停止增大校正训练；覆盖范围扩大本身不是成功。若最终主要依靠 D，保留这一结果，下一轮先做 D 单候选与先验替换的匹配重训，而非增加模块。动态融合须在完全相同、冻结候选上单独比较；物理项须与同容量无约束及等价重加权对照比较。任何新确认测试需再次冻结方案并另留原景，不回用本轮已暴露测试调参。

本轮在既定三个主要模型处收敛，没有继续搜索。若另开最多三个模型、各三个种子18轮的匹配消融，按实测 AMP 吞吐及预计算/评价余量估计需约 **40–55 V100 分钟**；该后续轮尚未启动，真实背景的数据资格、成像域和分组整理需另计。优先解决同输入小回归更强、单种子不稳定和 A/域外共同低估，再决定 D 单候选、完整三候选和同输入直接回归的匹配重训。当前不建议先追加动态或物理模块；没有要求购买、调整或删除资源，也没有新的资金确认请求。
