# 联合校正构建与运行协议

本轮目标仍为：相同配对数据、监督和训练机会下，受限候选校正能否以相近或更少参数接近同骨干RGB回归，并公开完整推理成本。

按用户本轮修订，不执行因未达标而终止结构探索、切换纯RGB或精简先验，也不启动真实遥感来源核验和新的确认测试。效果和成本的失败证据仍原样保留。只登记两个主要新模型，不自动扩张候选或增添语义、物理、去雾、检测分支。

## 已完成的等价优化

新FastCandidates保持FP32数学定义，合并共享引导滤波统计、缓存并批处理单调标定表；保留原始强度、固定训练标定、幂变换、引导滤波和边界规则，无逐图拉伸。

CPU/CUDA随机、零、常量、边界尺寸样例和512个旧开发样本特征差均为0；已训练校正器抽查输出差为0。测试阈值预登记为特征1e-6、网络1e-5，实际检查结果更严格。

256像素先验p50从3.81ms降至1.32ms，已训练校正器完整计算9.61ms至6.83ms；512为13.00ms至10.54ms。这是相同权重的实现优化，不是新模型准确率或最终成本优势。优化的先验临时张量会增加部分峰值内存，最终须报告完整运行显存。所有使用先验的公平控制都使用同一优化实现；不能拿新优化耗时对比旧实现并归因为结构。

## 两组联合训练

joint_fixed：218358神经网络参数。joint_dynamic：221161参数。都从原18轮校正器开发选定检查点开始，追加18轮，保持同1536训练配对和512开发配对，与已完成36轮的纯RGB16/RGB32及同输入回归比较。监督更新机会均为6912次；优化目标结构与两阶段选点不同，不能宣称相同优化过程。原检查点可能选在第17轮，但前阶段18轮已用预算和机会均如实计入。

训练目标为最终H任务损失，加.25倍独立候选辅助损失；候选辅助权重沿用1:.25:.25。H任务损失沿用像素MSE、.5整体均值MSE和.25额外清晰响应。辅助权重只登记一个，不搜索。开发检查点仅按最终融合H任务损失选择。

固定组训练/选点使用前阶段训练集拟合的固定权重，选点冻结后仅训练集重新优化固定融合；同时报告原选点权重结果。动态组联合更新校正器与小门控，三候选仍各自受自身先验的有界增益/偏移变换约束，没有自由H残差。校正和融合保持独立可评价输出。

联合训练后候选会变化，因此不能把新旧两阶段差异全部归因于某一单因素；已有完全冻结候选的固定/动态对照继续保留。新动态模型另提供自身冻结候选的重新优化固定融合以及空间权重干预。
